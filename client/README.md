# client

The React frontend. See the [project README](../README.md) for what this is and how to run it.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

Data currently comes from the in-browser mock API in `src/lib/api.js`
(`USE_MOCK = true`). Phase 4 switches it to the Express server.
